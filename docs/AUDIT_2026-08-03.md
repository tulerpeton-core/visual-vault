# Visual Vault — технический и UI/UX-аудит

Дата: 2026-08-03  
Версия после исправлений: 0.5.6  
Платформа: Windows 10/11 x64, Electron 43

## Итог

Приложение готово к production-публикации исходников и автоматической сборке. Код опубликован под MIT. EXE распространяются без Windows code signing с явным предупреждением и SHA-256.

## Проверено

- source/runtime inventory и состав ASAR;
- Electron security model, preload и IPC;
- SQLite, импорт, backup/restore, удаление и файловые пути;
- npm production audit;
- installer/portable-конфигурация;
- light/dark UI, splash, titlebar, карточки и контекстное меню;
- минимальное окно 760×560;
- focus states, dialogs, reduced motion и forced colors;
- GitHub-документация и CI.

## Исправлено в 0.5.6

### Security

- main renderer: `sandbox: true`, `contextIsolation: true`, `nodeIntegration: false`;
- запрет `window.open`, renderer-навигации и web permissions;
- проверка сигнатуры изображения вместо доверия MIME/data URL;
- SVG-импорт отключён;
- лимит одного изображения 200 МБ;
- filenames, tags, colors, ids, shortcuts и settings нормализуются;
- settings JSON ограничен 2 МБ;
- backup ограничен 512 МБ compressed / 1 ГБ unpacked;
- запись изображения и SQLite-record объединены безопасным rollback;
- CSP усилен `form-action`, `frame-src`, `media-src`, `connect-src`.

### Release engineering

- версия поднята до 0.5.6;
- добавлены `npm run check` и deterministic security checks;
- неиспользуемые demo/legacy assets исключены из package;
- добавлены `.gitignore`, `.gitattributes`, changelog, security policy, contribution guide, GitHub templates и Windows CI;
- README переписан под реальное текущее приложение.

### UI/performance

- grid-картинки используют lazy loading и async decoding;
- проверен compact layout 760×560: sidebar сворачивается, toolbar остаётся доступным, карточка не обрезается;
- подтверждены единый фон titlebar/content и theme-aware Windows icons;
- splash остаётся двухсекундным и поддерживает reduced motion.

## Оставшиеся риски

### P0 — внешний релизный риск

1. **Code signing отсутствует.** Portable и installer 0.5.6 проверены: `NotSigned`. Следствие: SmartScreen и низкое доверие загрузки.

### P1 — следующий релиз

1. **Нет thumbnail cache.** Lazy loading снижает нагрузку, но grid всё ещё декодирует originals. Большие библиотеки потребуют `thumbnails/` и фоновой генерации.
2. **Backup memory-bound.** Создание и restore держат JSON/base64 в памяти. Лимиты защищают от bomb-файлов, но крупные vault нужно переводить на streaming archive.
3. **Синхронный файловый I/O.** Импорт/backup большого файла может кратко блокировать main process. Нужен worker/stream pipeline.
4. **Нет автообновления.** Для beta допустимо; обновления публикуются вручную через GitHub Releases.

### P2 — дизайн-система и accessibility polish

1. Перенести повторяющиеся цвета, radii, shadows и spacing в semantic tokens.
2. Локализовать оставшиеся English `aria-label` в русском режиме.
3. Добавить automated contrast/focus regression и скриншоты 760×560, 1200×820, 150% scale.
4. Разбить 2000+ строк `app/index.html` на тестируемые компоненты. Текущий custom runtime усложняет CSP и требует `'unsafe-eval'`.

## Решение по релизу

- **GitHub source release:** готово, MIT.
- **Unsigned production EXE:** готово с явным предупреждением и SHA-256.
- **Signed production EXE:** отложено до появления code-signing сертификата.
